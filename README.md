# Dulce Equilibrio

Juego 3D donde controlas un osito de gomita que recorre islas
de dulces, esquiva obstáculos y recoge objetos para sumar puntos.

## Controles
- WASD o flechas: moverse.
- Shift izquierdo: correr mientras se mantiene presionado.

## Cómo funciona
- Los caramelos suman 1 punto.
- Las paletas especiales suman 3 puntos.
- Al llegar a 15 puntos, la partida se reinicia y reaparecen los dulces.
- Si caes al vacío, vuelves al inicio conservando tu puntaje.

## Cómo jugar
Abre el proyecto en Unity 6000.2.3f1, abre la escena
SampleScene y presiona Play.
